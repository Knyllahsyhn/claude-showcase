# claude-showcase

Eine kleine Machbarkeitsstudie: was [Claude Code](https://claude.com/claude-code) in ein paar Minuten aus einem leeren Ordner macht — für einen Kumpel, der wissen wollte, was das Ding eigentlich drauf hat.

Kein Backend, keine API-Calls, kein Build-Step. Reines HTML/CSS/JS, gehostet auf GitHub Pages.

## Was drin ist

- Ein Roast-Generator, ein Ausreden-Generator und ein Compiler-Horoskop (alles clientseitig, alles Unsinn)
- Ein ASCII-Art-Renderer, der echtes Pixel-Sampling über eine Canvas macht — kein Font-Trick
- Ein vollständig spielbares Snake, gebaut mit `<canvas>`
- Ein "Build-Log", das den tatsächlichen Verlauf der Session nacherzählt, in der diese Seite entstanden ist

## Lokal ansehen

Einfach `index.html` öffnen. Kein `npm install`, kein Server nötig.
